# Phase 0 & Phase 1: サイバーパンク都市ワールド仕様書

## 1. 時代設定と基本方針
- **時代設定**: 2060年[cite: 1]
- **世界観**: AIと人間が共生するサイバーパンク都市[cite: 1]。
- **コア体験**:
  - 街を歩く[cite: 1]
  - イベントへ参加する[cite: 1]
  - 仕事をする／しない[cite: 1]
  - 人間関係を築く[cite: 1]
  - 自分のお金を使って生活する[cite: 1]

## 2. 生活システムの設計思想
- 学校や仕事がシステム上の強制ミッションになるわけではない[cite: 1]。
- 参加するかどうかは、社会や人間関係の中で決まっていく[cite: 1]。
- 例えば、学校に行かないことで友人関係や周囲からの見られ方が変化するといった形で、ルールではなく社会的な結果として生活が形成されることを目指す[cite: 1]。

- **Phase 1**: プロトタイプ実装（VRChat / Unity 2022.3.22f1 環境での街の構築・生活の最小単位の実装）[cite: 1]
